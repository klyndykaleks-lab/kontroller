# Blue Pill F103 Button Board

Читайте `docs/PINOUT_V2.md` и `protocol/i2c-button-board.md` перед изменением
проводки, дебаунса, адреса или формата. Эта плата только фиксирует нажатия
десяти кнопок и отдаёт read-only snapshot по I2C `0x10`. Цена, терминал,
MDB и запуск мотора принадлежат F411/ESP. Возврат шины после ошибки должен
быть конечным, а удержанная или занятая кнопка не создаёт новую покупку.
После изменения выполнить `./scripts/verify.sh`, `./scripts/build-all.sh`
и физические P05–P08 из `docs/TEST_PLAN.md`.
